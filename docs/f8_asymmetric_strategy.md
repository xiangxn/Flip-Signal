# F8 非对称做市策略

## 概述

**F8 非对称做市策略** 是一个针对 Polymarket BTC 5 分钟 UP/DOWN 市场的做市策略。

策略不预测 BTC 涨跌方向，而是利用 **split + 双边挂限价卖单** 的方式，在 PM 盘口价格稳定的条件下，从双边价格波动中赚取 spread 利润。

核心逻辑就一句话：**如果开盘 80 秒内 PM 的 yes/no 价格几乎没动过 → split 挂双边卖单，低价侧多加 spread。**

---

## 策略原理

### 为什么能赚钱？

Polymarket 5 分钟市场的 yes/no 价格在窗口内会来回波动。中位数价格振幅高达 0.59（即价格从 0.5 可能荡到 0.2 又荡回来）。

当我们 split 5 USDC → 5 UP + 5 DOWN（成本各 2.5）后，双边挂限价卖单。只要价格往两边都稍微动一下，两侧都能成交，赚的就是 spread 的双倍利润。

### 为什么需要 F8 过滤器？

如果不加过滤直接交易，问题在于：约 ~57% 的 event 价格会单边趋势运行——只有一侧能成交，另一侧归零。单侧成交平均亏 -$1.32，两侧成交平均赚 +$1.25，总期望为负（-$71.33 / 242 ev）。

F8（价格稳定性）过滤器的逻辑：如果在开盘 80 秒时 yes/no 价格几乎没发生任何变动，说明市场处于犹豫/摇摆状态，后续价格大概率会在两个方向上来回试探，两边都有机会成交。F8 > 0.95 将单侧率从 57% 压到 29%。

### 为什么用非对称 spread？

高价 token（如 0.68）贴近上限 1.0，上涨空间有限。低价 token（如 0.31）远离上限，上涨空间更大。

因此**低价侧多加 spread，高价侧少加 spread**，在维持总成交率的前提下，最大化盈利。

Spread 分桶回测（见下文）显示，在 F8 > 0.95 过滤后，**每侧 spread ≥ 0.12（总 spread ≥ 0.24）是有效的盈利区间**。

## 策略参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 入场时间 | **距收盘 220s**（开盘后 80s） | 给两侧足够震荡时间，又不会太早让噪声干扰 |
| 热身期 | **60s** | 开盘后前 60 秒只积累特征不下注 |
| Split 金额 | **5 USDC** | 每次 split 获得 5 UP + 5 DOWN |
| F8 阈值 | **> 0.95** | price_stability 高于 0.95 才入场 |
| 高价侧 spread | **+0.12** | 高价 token（>0.5 的那一侧）的加价 |
| 低价侧 spread | **+0.14** | 低价 token（<0.5 的那一侧）的加价 |

### F8（price_stability）定义

```
F8 = 1.0 - min(|yes_end - yes_start| + |no_end - no_start|, 1.0)
```

即：开盘到入场时刻，yes 和 no 价格累计变动幅度的补数。

- F8 = 1.0：价格完全没动（最优）
- F8 = 0.9：价格变动了 0.1（比如 yes 从 0.5 → 0.55，no 从 0.5 → 0.45）
- F8 < 0.8：价格大幅波动（不入场）

**阈值 0.95** 意味着：yes+no 累计变动 < 0.05（几乎完全静止）。

### 非对称 spread 规则

| 场景 | yes=0.68, no=0.31 | yes=0.48, no=0.51 |
|------|-------------------|-------------------|
| 高价侧 | yes 是高价 → spread=0.12 | no 是高价 → spread=0.12 |
| 低价侧 | no 是低价 → spread=0.14 | yes 是低价 → spread=0.14 |
| yes 挂单 | 0.68 + 0.12 = **0.80** | 0.48 + 0.14 = **0.62** |
| no 挂单 | 0.31 + 0.14 = **0.45** | 0.51 + 0.12 = **0.63** |

> **注意**：这里的 spread 指每侧分别加价。例如 sp=0.12 意味着 yes 和 no 各加 0.12（以中间价 0.50 为例，两侧各溢价 24%）。按传统做市 bid-ask spread 口径，总 spread = 0.24。

## F8 分桶分析

F8 过滤器的核心假设是：**F8 越高 → 价格越稳 → 两侧成交率越高 → P&L 越好**。用更新后的回测数据验证（sp=0.12/0.14）：

|---------|---------|------|-------|-------|-------|-------|------|
| [0.80, 0.85) ⚠️ | 23 | 23 | 52.2% | 47.8% | -$3.05 | -$0.133 | 52.2% |
| [0.85, 0.90) ⚠️ | 25 | 25 | 32.0% | 68.0% | -$22.60 | -$0.904 | 32.0% |
| [0.90, 0.92) ⚠️ | 6 | 6 | 33.3% | 66.7% | -$4.10 | -$0.683 | 33.3% |
| [0.92, 0.94) ⚠️ | 5 | 5 | 40.0% | 60.0% | -$3.00 | -$0.600 | 40.0% |
| [0.94, 0.96) | 9 | 9 | 55.6% | 44.4% | +$0.45 | +$0.050 | 55.6% |
| [0.96, 0.98) | 12 | 12 | 58.3% | 41.7% | +$0.50 | +$0.042 | 58.3% |
| **[0.98, 1.01)** | **11** | **11** | **81.8%** | **18.2%** | **+$7.30** | **+$0.664** | **81.8%** |

> ⚠️ 标注的区间低于 F8 阈值 0.95，属于"若强行交易"的假设回测。实盘不会交易这些区间。

**结论**：

1. **F8 的单调性成立**：F8 越高 → 两侧成交率越高 → P&L 越好。F8 < 0.94 均亏损，F8 ∈ [0.94, 0.98) 微利，F8 ≥ 0.98 大幅盈利。

2. **阈值 0.95 的选择合理**：F8 ∈ [0.94, 0.96) 仅微利（均 $0.05），而 F8 < 0.94 全部亏损。0.95 恰好是盈亏分界线。

3. **F8 ≥ 0.98 是最佳区间**：11 笔交易，81.8% 两侧成交，均 P&L +$0.664。如果 F8 阈值提到 0.98，只交易 11 笔但总 P&L $7.30（比 24 笔的 $9.05 少了 $1.75，但胜率大幅提升）。

## 实盘执行流程

```
1. 等待 5 分钟市场开盘
2. 热身期（0-60s）：只采集快照数据，计算历史波动率、PM 价格等特征，不下注
3. 距收盘 ~220s 时（开盘后 80s）：
   a. 计算 F8 = 1.0 - |yes变动| - |no变动|
   b. 如果 F8 < 0.95 → 跳过本轮，等待下个市场
   c. 如果 F8 ≥ 0.95 → 执行 split + 挂单
4. Split 5 USDC → 5 UP + 5 DOWN
5. 挂限价卖单：
   - 如果 yes > no：yes 挂 yes+0.12, no 挂 no+0.14
   - 如果 no > yes：yes 挂 yes+0.14, no 挂 no+0.12
   - 价格上限 0.99
6. 等待成交至市场收盘
7. 未成交 token 按结算价处理（赢=1.0, 输=0.0）
```

## 固定 220s vs 扫描入场

_是否可以不用固定 220s，而是从 220s 开始向后扫描，F8 满足即入场？_

测试了多种扫描策略（卖侧 F8）：

| 策略 | 笔数 | 两侧成交 | 总P&L | vs固定 |
|------|------|---------|--------|--------|
| **固定 220s + F8>=0.95** | 24 | 70.8% | **$9.05** | baseline |
| 扫描 220→60 + F8>=0.95 | 114 | 66.7% | 低于固定 | — |
| 扫描 220→200 仅20s窗口 | 74 | 68.9% | 低于固定 | — |
| 避开180s死区 rem∉[160,200) | 103 | 68.0% | 接近固定 | — |

**结论：固定 220s 最稳健。** 原因：

1. **180s 是死区**：rem 在 160-200s 时 F8>=0.95 是假信号。价格安静 2 分钟但随时可能单边启动，只剩 ~3 分钟不够双边成交。

2. **F8 在 220s 的信号质量最高**：220s 时 F8>=0.95 意味着价格从开盘就一直稳定，且有 220s 的时间留给双边震荡。

3. **扫描增加交易但不增加质量**：放宽入场条件带来的额外交易大多以单侧成交告终。

**实盘建议**：固定 220s。如果非要提高频率，从 220s 扫描到 200s，超时不满足就跳过。

## 风险与限制

1. **样本量有限**：243 个 event 的回测数据，F8 过滤后仅 24 笔交易。统计显著性不足，实盘表现可能有偏差。

2. **做市商竞争**：Polymarket 上有专业做市商。如果他们也用类似的策略，spread 会被压缩，填单率下降。

3. **Split 执行**：实盘中 split 操作需要对手方。如果市场流动性不足，split 本身可能产生滑点。

4. **Gas 费用**：未计入。每笔 split + 两笔卖单 ≈ 3 笔链上交易。

5. **极端行情**：BTC 突然剧烈波动时，即使 F8 > 0.95，价格也可能瞬间单边走，导致一侧无法成交。

6. **Spread 参数过度拟合**：24 笔样本上搜索最优 spread 组合容易过度拟合。对称 sp=0.12（仅 1 个参数）比非对称 0.16/0.22（2 个参数）更稳健。建议实盘先用对称 sp=0.12，积累更多数据后再微调。

7. **买侧策略实测亏损**：详见 [asymmetric_spread_formula.md](asymmetric_spread_formula.md)。买侧 NoFilter + 公式实测 -$45.55，逆向选择无法克服。如果只上线一个策略，**卖侧 + F8 > 0.95 是唯一正期望的选择**。
