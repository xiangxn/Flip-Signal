## §1 逻辑梳理：三线象限表（以 anchor 为中心）

判定只用到三个量（下注侧 X 的符号 sgn：押 yes +1 / no −1）：

- `dev(X) = sgn·(spot − anchor)` —— 现货腿（现货相对锚）
- `walk(X) = sgn·(twap − anchor)` —— 结算线腿（TWAP-60 相对锚，**已写进结算线的位移**）
- 恒等式 `dev = basis + walk`（`basis = sgn·(spot − twap)`）。

## §2 v2 定义（线腿 = arm_line）

「不同侧另一套逻辑」的落地形态 = **现行链 + 线腿**，三段判定链、价格腿、
σ 路线、#29 闸、地板**全部照现行**，只加一条：

```
arm_line(stage) = dev < 0 ∧ walk ≥ W ∧ dev ≤ −G          （W、G 为扫描参数，美元）
信号 = arm_spot（现行，逐字不动） ∨ arm_line
```

- 语义：市场热门侧 + 结算线（walk）都站在 X 一边（价格腿与 #29 闸管价格与 walk 下限），
  唯独现货（dev）在对面 ⇒ 补一个买 X 的入口。
- **超集性质**（脚本断言）：arm_spot 逐字不动 ⇒ 逐 tick 上 `v2 ⊇ 现行`
  ⇒ 只可能「保持 / 改写（更早成交）/ 新增」，**理论上不丢单**（§0 已断言 lost=0）。
- **Δ 一律配对口径**：`Δ = v2(cfg) − base(cfg)`，其中 `base(cfg)` = **同参数**但关掉线腿
  （不是默认现行）——这样 §3 的邻域变体也在同一参数下比，Δ 只度量线腿自身增量；
  默认参数下 base == 现行链（§0 pin 已钉）。
- 改写（更早成交）分两形：**同侧**（同 outcome，只是买得更早/更便宜）与
  **异侧**（v2 买 X 而 base 稍后买对面 Y——市场侧别翻转过，**抢单**）。

### 三条读法

**① 被放弃的支路本身是正口袋（两腿分解都在 New 批上为真）**：
新增批在任何 W 档下都是高胜率正余量——W=0：n=1030 WR 96.12%、fill 均 0.9272、
余量 +3.40pp、净 +69.54U [+13.93,+126.95]；W=43：n=163 WR 98.77% +6.96U；
侧别几乎全 NO（1026:4 events）。⇒ 「现行链整窗没找到单」的那些窗里，
**市场热门侧 + 结算线同向、现货反对**这一组合是真实的正口袋。

**② 直接接进链会「抢单」，浅档被抢单吃光**：
W=0/G=0 改写 80 窗 Δ **−96.86U** [−144.97,−54.78]，分解 = 同侧 23 窗 **+3.90U**
‖ **异侧 57 窗 v2 赢 5 / 基赢 52，Δ −100.76U**。异侧 = 市场侧别翻转窗：
线腿在混合态提前买 X，随后现货穿过 anchor、热门侧翻到 Y，现行链本会买赢家 Y。
**两样本里这类窗几乎全是「v2 输 / 基赢」**（events 5/57、btc 0/21）——
现货方向对、线/价方向错的窗，正是抢单的全损来源。

**③ 深阈值能消掉抢单，但新增批也一起缩没**：
G（要求现货在押注侧对面 ≥G 美元）使"抢单"所需现货回穿距离 ≥ G+63 美元，几何上更难发生；
W 同理（结算线已朝押注侧走 W 美元后市场翻转更少）。
events 上 `(20,63)` 改写清零、Δ **+2.72U [+0.49,+5.50]**（全网格唯一下界明显 >0 的格）；
`(30,63) +0.87 [+0.04,+1.89]`、`(43,40) +1.25 [+0.32,+2.23]`。但量级只有 **+0.9~+2.7U/15 天 @2U**。

## §7 结论

1. **用户命题成立**：现行链在「异侧」状态（Q3 spot>anchor>twap / Q4 镜像）确实放弃
   了该侧信号；该类窗口 events 1681 / btc 1067（Q4：14 / 176），成交 0 笔。
   该支路**自身是正口袋**（新增批两样本下界 > 0；Q4 在 btc 上也不是空类）。
2. **但「接进现行链」的形态不成立**：它必然与现货腿抢单（异侧改写 = 市场侧别翻转窗，
   两样本合计 78 窗、v2 赢 5 / 基赢 73、Δ −146U）；把抢单压掉的深阈值又让新增批缩到
   +0.2~+2.7U/14 天量级。
3. **两样本联合判据无一格通过**：events 上 Δ 下界 > 0 的格（(20,63)/(30,63)/(43,40)）
   在 btc 上分别 −2.09 / +0.23 / +0.43；btc 全网格 24 格 Δ 下界 > 0 的格数 = 0。
   两样本同号为正的只有深角，量级 ≤ +1.3U/14 天 @2U ——
   与既有前向判据量级（+10U/14 天）差一个数量级，属经济上无意义。
4. **不落引擎**。若将来要重提，前置条件（先写死再跑）：
   ① 两样本（新采集 ≥14 完整日 + data/btc）同格 Δ 下界 > 0 且量级 ≥ +10U/14 天 @2U；
   ② 抢单窗（异侧改写）占比与损益单独报告；③ 明确"抢单"不是可调参数抹掉的现象
   ——它是现货方向对了的窗（78 窗里基赢 73），任何把它过滤掉的机制都必须先证明
   「入场时刻可判现货不会回穿」（对照：`48` 号 §8 已证状态量对未来位移无预测力）。
