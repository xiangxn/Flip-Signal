## 3. 已知 live 与回测数据口径差异（量化）

| 维度 | 回测 | live | 影响 |
|---|---|---|---|
| tick 相位 | 数据首 tick rem≈298/297 | ticker 首 tick rem≈299/300 | ±1-2 tick；仅 45 窗边缘与 rem>180 门槛 ~10 行/14 天受扰。**对账用 ts 对齐不用 rem** |
| anchor（twap_open） | 官方开盘价 | 边界瞬间 TWAP 流值 | p50 差 0.08bps / p99 1.14bps（σ≈7bps），个别尾巴事件可能推过带边界——记录在案，复验比分布不逐笔对账 |
| hist（σ） | 前 ≤18 已完窗官方 `|tw_close−tw_open|` | 启动 `FetchTwapRanges` 官方范围预热；此后每窗结束追加**流值** close | close 流值与官方恒等（结算口径=TWAP），差异仅历史窗口条数 → 均值影响 ≤1/18 |
| spot 缺失 | 秒桶：该秒无 bin tick → price 缺 | BinanceAdapter 保留最后价 + 本地接收龄 | 引擎：RxAge>2s → BinPrice=0（missing_spot）。BTC 常态每秒多笔成交，几乎不误报 |
| book_latency | 数据行内字段 | WS 消息 Latency（SDK 算） | 同源口径 |
| m_45 窗口 | 数组索引 [i−45,i−1]（dt=i−j 索引距离） | 索引槽位 ring（先判后插、无效 tick 压 0 占槽） | **等价**：python 的 dt 是索引距离，无效 tick 以间隔隐式占位；引擎显式压 0——窗口成员与 max 完全一致 |
| reject 分解 | 无（掩码入选） | rem_low → no_hist → missing_spot → no_crash → dist_out（顺序固定；missing_anchor 现网不可达——锚缺失窗口整窗早退，见 §触发口径） | 纸面按原因频率校准，09-15 与实测分布对比（触底 ~260/日：rem_low ~40%、no_crash ~26%、入选 ~6-7%） |

## 4. 运行与部署

```bash
# 本地纸面（需代理，见 CLAUDE.md 运行方式）
go run ./cmd/flip -output data/v4 -dashboard :8090

# 参数示例（与回测常量同名）
go run ./cmd/flip --trigger-ask-max 0.2 --crash-min-ask 0.4 --stake 2
```

服务器：`./build.sh && ./deploy.sh` → `nohup ./flip -output data/v4 -dashboard :8090 >> flip.log 2>&1 &`
拉数据：`./down.sh v4` → `python/v4/02_paper_compare.py`。

**⚠️ 部署机环境**：Binance 适配器拨号走 `http.ProxyFromEnvironment`——服务器直连
Polymarket 用 SOCKS5（`POLYMARKET_PROXY`），但**勿设指向不通代理的 HTTP(S)_PROXY**，
否则 Binance spot 永不连上、全部信号 missing_spot。
