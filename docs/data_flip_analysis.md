## 10. 推荐交易信号

### 信号设计原则

所有信号只使用 **>0.7 穿越时刻及之后 5 秒内已知的信息**，无未来信息偏差。

### 最终信号: 三层过滤

```
═══════════════════════════════════════════════════════════
Layer 0 — 前置条件 (Pre-filter):
═══════════════════════════════════════════════════════════
  1. Polymarket 一边价格 > 0.7
  2. 只在第一次穿越时触发 (避免重复入场)

═══════════════════════════════════════════════════════════
Layer 1 — 振幅 + 路径过滤 (振幅扩张 + 双边震荡):
═══════════════════════════════════════════════════════════
  条件(必须全部满足):
    A. 路径类型 = 双边震荡 (path_eff ≤ 0.4)
       含义: 价格来回拉锯，多空激烈交火，不是单边趋势
       判断: abs(当前BTC价 - Open) / 穿越前振幅 < 0.4
             噪声比 (累计路径 / 净移动) > 5
             方向翻转次数 > 10

    B. 振幅扩张 1.0x ~ 3.0x (黄金区间)
       含义: 当前K线振幅大于历史均值但不过大，波动异常但可控
       判断: 当前已走振幅 / 前12根K线平均振幅 在 [1.0, 3.0)

    C. 振幅过大否决: 扩张 ≥ 3.0x → ❌ 真突破, 直接跳过!
       数据: ≥3.0x 时翻转率仅 14.3% (n=7), 低于 baseline 25.3%

  过滤逻辑:
    振幅 ≥ 3.0x   → ❌ 真突破，一票否决
    单边趋势 (eff>0.6) → ❌ 不下注 (翻转率仅34.5%)
    双边震荡 (eff≤0.4) → ✅ 继续到 Layer 2

═══════════════════════════════════════════════════════════
Layer 2 — 入场确认 (对面价格5秒运动):
═══════════════════════════════════════════════════════════
  条件: 穿越后 5 秒，对面价格上升 > 0.02

  含义: 市场正在用钱投票反对 PM 的方向。
        对面价格上升 = 有人在大举买入对面 → 翻转进行中。

  确认效果:
    对面↑ >0.02: 翻转率 42.6% (整体)
    双边+对面↑:  翻转率 60.9% (叠加路径过滤后!)

  动作:
    - YES > 0.7 → 买入 NO (做空，赌 DOWN 赢)
    - NO  > 0.7 → 买入 YES (做多，赌 UP 赢)

  入场价: 对面价格 (此时通常 0.20-0.28)

═══════════════════════════════════════════════════════════
Layer 3 — 加仓条件 (可选):
═══════════════════════════════════════════════════════════
  条件: 对面价格继续上升 > 0.03 (累计)

  含义: 翻转趋势确认，加仓。
```

### 信号流程可视化

```
PM一边 >0.7 ?
  ├─ NO  → 不交易
  └─ YES → 振幅≥3.0x历史?
            ├─ YES → ❌ 真突破, 一票否决 (翻转率仅14.3%)
            └─ NO  → 路径类型?
                      ├─ 单边 (eff>0.6) → ❌ 不交易 (趋势延续概率大)
                      └─ 双边 (eff≤0.4) → 振幅扩张?
                                            ├─ 振幅<1.0x历史 → ⚠️ 弱信号
                                            └─ 振幅1.0-3.0x → 对面5s上升?
                                                              ├─ NO  → ❌ 不交易
                                                              └─ YES → ✅ 入场!
```

### 风控规则

1. **只在第一次 >0.7 穿越时入场** — 不要在每个 snapshot 都重复入场
2. **振幅过大不交易** — 扩张 ≥ 3.0x 是真突破，一票否决 (翻转率仅 14.3%)
3. **双边路径才入场** — 单边趋势中 PM 的方向大概率正确
4. **对面价格必须确认** — 没有对面上升确认，不交易
5. **每笔等仓位** — 固定 share 数或固定金额
6. **持有到结算** — 二元结果，不设止损
7. **避开持平行情** — 路径效率在 0.4-0.6 之间的模糊地带不交易

| 105 USDT | 58 USDT | 1.8x | NO→UP | 0.26 | ❌ |

### 结论

振幅扩张**叠加** BTC 极端位置后，翻转率从 46% 提升到 **55-67%**。

**直觉解释**: 
- 前面几根 K 线振幅都 ~60U → 正常波动
- 当前 K 线已经 120U+ → 异常放量，多空分歧加剧
- Polymarket 还在 >0.7 赌趋势延续 → 但实际上这么大的振幅说明趋势已经过度延伸
- **振幅扩张 + BTC 极端 + 高置信度 = 趋势衰竭信号**

但注意: 振幅 ≥ 3.0x 的极端情况样本太少 (n=7)，翻转率仅 14.3% (低于 baseline 25.3%)。这是真正的突破行情，**必须一票否决、不交易**。已在信号设计 Layer 1 中加入硬过滤。

## 12. 纯实时信号分析 (无未来信息偏差)

> **重要**: 前面第 11 节使用的事件级 `close-open` 有未来信息偏差 —— 收盘价只有事件结束后才知道。本节只用 >0.7 穿越时刻及之后 5 秒内**已知**的信息来做信号。

### 12.1 可用的实时特征

| 特征 | 计算方式 | 可知时间 |
|------|---------|---------|
| BTC实时方向 | 当前BTC价格 vs Open | 穿越时刻 |
| BTC位置(穿越前) | (当前价 - 穿越前最低) / 穿越前振幅 | 穿越时刻 |
| 路径效率 (eff) | abs(当前价-Open) / 穿越前振幅 | 穿越时刻 |
| 噪声比 | 累计路径 / 净移动 | 穿越时刻 |
| 方向翻转次数 | 穿越前 tick 级别方向变化 | 穿越时刻 |
| 振幅扩张 | 穿越前振幅 / 历史均值 | 穿越时刻 |
| **对面价格5s变化** | 穿越后5秒 对面价 - 穿越时对面价 | **穿越+5s** |
| Signed Flow, Depth | 实时 WS 数据 | 穿越时刻 |

### 12.2 BTC 实时方向 vs Open

### 12.3 最强实时信号: 对面价格 5 秒确认 ★★★

**效应量 0.8** — 这是唯一统计和经济双显著的实时信号。

### 12.4 用户假设验证: 单边 vs 双边路径

> 用户假设: "单边不能下注，双边可以下注"

**验证结果: 用户正确!** 但需要对面确认信号配合。

| 路径类型 | 对面确认 | N | 翻转率 | 结论 |
|---------|---------|---|--------|------|
| 双边 (eff≤0.4) | 对面↑>0.02 | 23 | **60.9%** | ✅ 下注! |
| 单边 (eff>0.7) | 对面↑>0.02 | 58 | 34.5% | ⚠️ 不太行 |
| 双边 (eff≤0.4) | 对面↓>0.02 | 56 | 14.3% | ❌ 不下注 |
| 单边 (eff>0.7) | 对面↓>0.02 | 78 | 10.3% | ❌ 不下注 |

**交易规则**:
- ✅ 双边震荡 + 对面价格开始上升 → **开仓** (60.9% 翻转)
- ❌ 单边趋势 + 无论对面怎么走 → 不开仓
- ❌ 对面价格在下跌 → 无论什么路径都不开仓

**逻辑**: 双边震荡说明多空在激烈交战，PM 选了一边 >0.7，但对面价格开始上升 = 市场在用钱投票反对 PM 的方向 → 翻转概率高。
