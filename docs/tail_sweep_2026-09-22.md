# 扫尾盘 / 买尾盘热门方（tail sweep）—— data/btc 回测与结论（2026-09-22）

**一句话**：在窗口最后一段时间里，买当时报价 ≥0.80 的那一侧（"热门侧"），并可选加一层
「spot 与 TWAP-60 都朝该侧偏离锚」的过滤器——14 天回测下 **胜率随价位单调升到 99%+，
但成交价同步升到 0.98~0.99，EV/股 全程贴着 0 走**；唯一正期望的格子是「最后 60 秒」，
而它的收益来自"尾部事件 14 天没发生"，不是来自过滤器。

**性质**：纯分析（回测 + 分桶），**未落引擎、无策略代码改动**；新增分析脚本
`python/v4/13_tail_sweep.py`（本文件所有数字均可由它复现）。

**结论**：❌ **不建议落引擎**（理由见 §8.1；无法在纸面期复验见 §9）。与现行 dog@0.2
（买崩盘折价侧，EV +0.633U/注）互为镜像且不可叠加——edge 在折价侧，不在热门侧。

## 1. 策略定义与口径

### 1.1 用户原题（三条件）

1. 当某一侧价格达到 **≥ 0.80**；
2. 观察 **spot 与 TWAP-60 是否都站在该侧一边**（押 UP：两者都 > 锚；押 DOWN：两者都 < 锚）；
3. 成立则下注该侧。

**镜像对称口径**（用户 2026-09-22 选定）：押 DOWN 时两个量"都小于锚"即等价成立，不做单独处理。

### 1.2 本回测的落地口径（关键，必须照此复现）

| 项 | 定义 |
|---|---|
| **尾盘快照** | 每个窗口在 **`rem ≤ T` 的第一个有效 tick** 上取一次快照，买当时 ask 较高的一侧（**热门侧**）。**不是**"价格首次穿过某价位那一跳"（首次触达 0.9 的中位 `rem=211s`，那是窗口中段，不是尾盘） |
| T（尾盘起点） | 主口径 **T=120s**；另扫 240/180/150/90/60/30 |
| 有效 tick | `pm` 存在 + `book_latency_ms ≤ 300`（回测 `MAX_LAT`，与引擎同值）+ 四档报价（`yes_bid/yes_ask/no_bid/no_ask`）全 > 0 + `rem > 0` |
| 价格腿 | 快照上热门侧 `ask ≥ 0.80` |
| 成交 | `成交价 = 热门侧 ask`（吃单）；`股数 = 2 / 成交价`（2U/注）；赢 → `股数 − 2`，输 → `−2` |
| 结算 | 官方 `outcome`（0=Up / 1=Down）。已验证 **3753 窗里 `outcome` 与 `twap_close > twap_open` 100% 一致**（无口径错位） |
| **WR（胜率）** | 押注侧最终赢的比例 |
| **EV/股** | `WR − 成交价`（>0 才值得吃单） |
| **EV@中价** | `WR − 中间价`，`中间价 = (bid+ask)/2`（剔除买卖价差成本 → 看市场是否真定价错） |
| **σ（hist_bps）** | 前 ≤18 个已完窗口的 `|twap_close − twap_open|` 均值 ÷ 锚 × 1e4（单位 bps，万分之一）。**样本内 σ 中位 8.0 bps ≈ 63 美元**（下文括号里的"σ"均按此换算） |
| **同向归一** | 两个偏离量按"站在下注侧一边为正"取符号：押 UP 取 `+`，押 DOWN 取 `−`。记为 `spot − twap_open`、`twap − twap_open`（单位**美元**） |
| 基差 | `spot − twap`（两个偏离量之差） |

**数据**：`data/btc` 14 个事件文件（2026-08-18 ~ 08-31），**3753 个窗口**，1 秒 tick 级
（PM 盘口 / Binance spot / TWAP-60）。

## 9. 为什么不能在 data/v4（纸面期）上复验

**结论：做不到，且代理也补不上。**

- `data/v4` 只有 **4284 条 touch**（2026-09-03 ~ 09-18，16 天），每条 = 该事件**首次
  砸到 ≤0.20** 那一刻的快照（`side / rem / fill / spot / twap_price / anchor / hist_bps`），
  **没有 tick 序列、没有末分钟的两侧盘口**。策略要的是 `rem ≤ 60` 那一刻热门侧的
  成交价，该数值在 v4 数据里不存在。
  tick 级数据只有 `data/btc`（08-18~08-31）；采集管线 `cmd/collect` 在 v4 分支已删除。
- **代理尝试（已做，结果不可用）**：买"末分钟被砸穿"那一侧的对侧，成本用
  `1 − 狗侧ask`，偏差在 data/btc 上标定为 **正好等于狗侧买卖价差 = 0.0105 美元/股**
  （T=60/90/120 三次标定完全一致）。

  | 期间 | 选择口径 | n | 对侧胜率 | 校正后 EV/注 | P&L |
  |---|---|---|---|---|---|
  | 09 月纸面（data/v4） | 首次砸穿发生在 rem≤60 | 133 | 88.7% | **+0.096U** | +12.8U，日正 10/14 |
  | 08 月回测（data/btc） | 同上口径 | 97 | 84.5% | **−0.043U** | −4.2U |

  两期**方向相反、各仅 ~100 笔 ⇒ 纯噪声**。
- 而且该代理**不等于本策略**：这些事件在 `rem = 60` 时热门侧价格平均只有 **0.625**
  （比赛还没定），属"最后一分钟突然崩盘"族；本策略样本是"末分钟价格已在 0.80 以上"族。
  data/v4 只记「首次砸穿」，天然抓不到主体样本（data/btc 里 T=60 有 80% 落在 0.95 以上，
  且多为"早已砸穿、一路躺到结束"）。

## 11. 结论与后续

1. **用户原版三条件（≥0.8 + spot/TWAP 同向 + 尾盘）在 T=120 是 EV ≈ 0**，条件②无增量
   ⇒ **不建议落引擎**。
2. **要"胜率最高"**：T=60 + `spot − twap_open ≥ 60 美元`（0.96σ）或两腿都 ≥ 1.6σ，
   胜率 99.5~100%，14 天日正。但要认识到：**收益来自 T=60 这个时点，不是来自过滤器**
   （EV/股 从不过滤的 +0.011 到过滤的 +0.010，**没有提升**）；过滤器买到的是方差。
3. **与现行 dog@0.2 的关系**：同为 14 天口径，买崩盘折价侧 EV **+0.633U/注**；
   买尾盘热门方（T=120）EV **+0.006U/注** ≈ 0。**edge 在折价侧，不在热门侧**，
   两者镜像、不可叠加。
4. **若日后要继续追 T=60 那一格**：需要的是**更长的时间跨度**（跨月、跨波动率 regime）
   来检验那 1% 失败率会不会兑现，而不是更多窗口；且需先恢复 tick 级采集
   （`cmd/collect` 已删，复活见 `docs/dog020_mapping_2026-09-02.md §5`）。14 天窗口内
   既不能证实也不能证伪——与 dog@0.2 的"纸面 14 天好看、OOS 归零"是同一种风险形态。
5. **数据上唯一干净的副产品**：§6.1 的无条件预测力表（`spot − twap_open` 14%→99% 单调）
   可作其他策略的方向特征，但它已被价格定价，单独不可交易。
