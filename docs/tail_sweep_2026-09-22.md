# 扫尾盘 / 买尾盘热门方（tail sweep）——策略规格（最终选 ⑤）

**一句话**：在 5 分钟窗口的**最后 60 秒**，买当时报价 ≥0.80 的那一侧（"热门侧"），
条件是 **「现货相对锚的位移 ≥ 63 美元」**，**或** **「该窗 1σ 折美元 ≥ 40 美元 且 位移 ≥ 该窗 1σ」**。

**14 天回测（2026-08-18~08-31，2U/注）**：n=**1536**（110 注/日）、胜率 **99.6%**、
成交价 0.985、EV **+0.0240U/注**、P&L **+36.9U**、日级 95%CI **[+25.7,+49.2]**、
**单日最亏 +0.5U（无亏损日）**。

**性质**：纯回测分析 + 纸面登记规格。**未落引擎、无策略代码改动**（本族不接 `ExecState`/风控闸）。
**结论**：❌ 不上实盘（§4 的尾部风险）；✅ 纸面登记追踪，判据见 §5。

**脚本**（本文件所有数字均可由这三支复现）：
`python/v4/13_tail_sweep.py`（主回测/分桶/T 扫描）、`14_tail_sweep_sigma.py`（σ 尺子/σ 窗长/日级 bootstrap）、
`15_tail_sweep_union_sigma.py`（联合格 σ 分桶/门槛选择稳定性）。
**本文件的前身**（完整探索过程，936 行）保留在 git 历史 `c5720af`，本版按"策略规格"重写。

## 1. 策略规格（⑤）

### 1.1 逻辑

> 尾盘 60 秒时市场已经把某一侧顶到 0.98+ 的"必赢价"，此时**唯一的 alpha 来源是
> "现货是不是真的走出来了"**——走出来了（位移够大）就买它的确定性；没走出来但**窗口本身很静**
> （1σ 折算只有二十来美元）时，σ 门槛形同虚设，那批行是白干（§3.3）——故给 σ 腿垫一道美元下限。
> **不预测涨跌，只买"已经赢定的那一侧 + 现货确认"。**

### 1.2 逐条口径（必须照此复现）

| 项 | 定义 |
|---|---|
| **尾盘快照** | 每个窗口在 **`rem ≤ 60` 的第一个有效 tick** 上取一次快照，买当时 ask 较高的一侧（**热门侧**）。**不是**"价格首次穿过某价位那一跳" |
| 有效 tick | `pm` 存在 + `book_latency_ms ≤ 300`（与引擎 `flip.max_book_lat_ms` 同值）+ 四档报价（`yes_bid/yes_ask/no_bid/no_ask`）全 > 0 + `rem > 0` |
| 热门侧 | `yes_ask ≥ no_ask` → yes，否则 no |
| 价格腿 | 快照上热门侧 `ask ≥ 0.80`（低于 0.80 不记为该格样本） |
| **位移 dev** | `sgn × (spot − anchor)`，单位**美元**；`sgn = +1` 押 yes（UP）、`−1` 押 no（DOWN）。**归一化**：永远"朝押注方向为正" |
| **锚** | 该窗的 TWAP-60 开盘值（`twap_open_price`），即 Chainlink 结算线的起点 |
| **σ（hist_bps）** | 前 ≤18 个已完窗口的 `\|twap_close − twap_open\|` 均值 ÷ 锚 × 1e4（单位 bps）。**样本内中位 8.06 bps** |
| **1σ 折美元 sd** | `hist_bps × anchor ÷ 1e4`。**样本内中位 62.4 美元**（p25 = 40.1、p75 = 88.4） |
| **成交** | `成交价 = 热门侧 ask`（吃单）；`股数 = 2 / 成交价`（2U/注）；赢 → `股数 − 2`，输 → `−2` |
| **结算** | 官方 `outcome`（0=Up / 1=Down / gamma `umaResolutionStatus=="resolved"`）。已验证 3753 窗里 `outcome` 与 `twap_close > twap_open` **100% 一致** |
| 胜率 / EV | `WR = 押注侧最终赢的比例`；`EV/股 = WR − 成交价`；`EV/注 = P&L ÷ n = 2 × EV/股 ÷ 成交价` |

### 1.3 ⑤ 的判定（一行不等式）

```
dev = sgn × (spot − anchor)                 # 位移（美元，正 = 朝押注方向）
sd  = hist_bps × anchor / 1e4               # 该窗 1σ 折美元

买 ⟺  dev ≥ 63 美元   或   ( 40 美元 ≤ sd ≤ dev )
```

第二条腿的等值写法：`dev ≥ 1.0σ` ⟺ `dev ≥ sd`（因为 `dev/sd ≡ dev_bps/hist_bps`），
所以 σ 腿 = **"位移过 1σ，且这个 1σ 本身至少值 40 美元"**。

### 1.4 参数表

| 参数 | 值 | 出处 / 理由 | 可否调 |
|---|---|---|---|
| 尾盘起点 T | **60s** | T=60 上加过滤后剔掉最好的 4 天仍剩 +16.7U、日正 14/14；**T=120 加过滤救不回来**（剔 4 天后 −23.9U ~ +1.6U）；T=240 的候选格 CI 下界 −19U。见附录 §A 第 2 条 | 不可（T 换了逻辑就变，见 §4.4） |
| 价格腿 | **≥ 0.80** | 用户原题的"达到 0.80"；T=60 时 86% 的窗都满足（不是选择器），但它恰好切在唯一系统性为负的价位带 `[0.75,0.80)` 之后 | 不可 |
| 美元腿 | **≥ 63 美元** | = **本 14 天 1σ 折美元的中位（62.4 美元）**，即"位移 ≥ ~1σ"；换波动率 regime 会失义（见 §2 第 2 条） | 不可 |
| σ 腿门槛 | **≥ 40 美元** | ≈ 1σ 折美元分布的 **p25（40.1 美元）**；门槛扫描在 **30~50 美元 是一段平台**，40 是平台中点 | **不可调**（§4.3：40 从未在重采样里成为最优） |
| 每注 | **2U** | 脚本 `STAKE=2.0`，与 dog@0.2 同 | 可（等比缩放不影响结论） |
| 有效 tick 延迟闸 | **300ms** | 与引擎 `flip.max_book_lat_ms` 同值（收紧在 14 天回测里单调变差） | 不可 |
| σ 窗长 | **前 ≤18 个已完窗口**，≥3 窗可用 | 窗长 N=6~36 全扫 + 估计量替换（平均绝对变动 ↔ 均方根）**没有任何格位翻符号**；N=14 与 N=18 逐窗 **ρ=0.967**（几乎同一个变量）；N 缩到 5 反而把 ③ 拖差（+22.3U → +18.1U）。见附录 §A 第 6 条 | 不可 |

## 2. ①~⑤ 五条规则的逻辑与取舍

五条规则只差**过滤腿**，全部用同一条不等式表达（`dev` = 位移美元，`sd` = 该窗 1σ 折美元）：

| 规则 | 过滤腿（不等式） | n | 胜率 | 成交价 | EV/股 | EV/注 | P&L | 亏损日 | 逻辑一句话 |
|---|---|---|---|---|---|---|---|---|---|
| ① 不过滤 | 无 | 3109 | 97.7% | 0.966 | +0.0107 | +0.0232 | **+72.1U** | 3/14 | 基准：只要 ≥0.80 就买 |
| ② 纯美元 | `dev ≥ 63` | 1458 | 99.6% | 0.985 | +0.0108 | +0.0224 | +32.7U | **0/14** | 现货已朝押注方向走出一大截 |
| ③ 纯 σ | `dev ≥ sd` | 1469 | 99.5% | 0.987 | +0.0076 | +0.0152 | +22.3U | 1/14 | 同一逻辑换成可跨 regime 的尺子 |
| ④ 联合 | `dev ≥ 63` **或** `dev ≥ sd` | 1747 | 99.4% | 0.984 | +0.0095 | +0.0194 | +34.0U | 1/14 | 两把尺子取并集，兜住各自的漏 |
| **⑤ 定向** | `dev ≥ 63` **或** `40 ≤ sd ≤ dev` | 1536 | **99.6%** | **0.985** | **+0.0115** | **+0.0240** | **+36.9U** | **0/14** | ④ + 给 σ 腿垫美元下限 ← **选定** |

**逐条说明**：

1. **① 不过滤 = 原题的直接实现**（"尾盘 ≥0.80 就买热门侧"）。用户原题里的第二条
   （"spot 与 TWAP 同向"）已单独测过并发现在控价后**无增量**（附录 §A），故 ① 就是价格腿单腿。
   它的**总收益最高（+72.1U）**，但代价是全部规则里最差的三项：**3 个亏损日**、
   收益 **76% 集中在最好的 4 天**（08-25~28 连续四天 +55.1U，其余 10 天合计仅 +17.0U）、
   前半 +8.2U vs 后半 +63.9U。**它不是"更差的策略"，是"更大的暴露"**——见 §3.2。
2. **② 纯美元 = 加"现货确认"腿**（`位移 ≥ 63 美元`）。机理：现货已朝押注方向走出一大截，
   反转概率更低。效果：胜率 97.7% → 99.6%、**亏损日 3 → 0**、集中度 76% → 52%，
   但 **EV/注 微降**（+0.0232 → +0.0224）——它买的是**确定性**，不是更高的期望。
   致命弱点：**63 美元是本 14 天 σ 中位的产物**，换波动率 regime 就失去意义
   （本样本 1σ 折美元的 p90 已达 127 美元 ⇒ 同一个 63 美元在高波动 regime 里可能只值 0.5σ）。
3. **③ 纯 σ = 把同一条腿换成 σ 尺子**（`位移 ≥ 1.0σ`，可跨 regime）。效果：EV/注 最低
   （+0.0152）、有一天日 EV 为负；但它是**唯一守住频率的那一格**（日注数 88~123、9/13 天
   落在 90~120/日 的预设闸门内）。⇒ **σ 尺子守频率、美元尺子守日 EV，二者互斥**
   （附录 §A 第 8 条）。
4. **④ 联合 = 两把尺子取并集**（用户 2026-09-22 的原提议）。动机是"美元尺子在静窗里信号枯竭
   （08-29 只有 25 注）、σ 腿补这个下限，反过来 σ 腿在高波动窗里门槛过松、美元腿补上"。
   实际效果：**两腿的增量都是噪声级**——σ 腿独有的 289 注 EV/注 只有 **+0.0044**（≈打平），
   EV/注 被摊薄到 +0.0194（低于 ②）。且联合格**待调参数从 1 个变成 2 个**。
5. **⑤ 定向 = ④ 再给 σ 腿垫一道美元下限 40 美元**。剔掉的是"σ 腿放行、美元腿拒掉、
   而窗口本身很静（1σ 只有二十来美元）"的那批行——它们 EV/注 **−0.0140**（211 注，§3.3）。
   效果：EV/股 **+0.0115**、EV/注 **+0.0240**，**在 ①~⑤ 五条里双双最高**，同时保住 ② 的
   **0 亏损日**与最低集中度（50%）。**唯一"既提期望、又不亏稳定性"的一格。**
   （⑥⑦ 的名义 EV/注 更高（+0.0247 / +0.0254），但它们砍掉美元腿正 EV 行、日注数
   8~192 / 0~189，总收益反而更低——见下。）

**另有两条"字面实现"⑥⑦（用户原话的另一种落法：整窗 1σ 低于 F 就整窗丢掉）已证伪**：
它们**连美元腿的好行一起杀**（窗口 σ<40 的美元腿行 163 注 EV +0.0183；窗口 σ<63 的 494 注
EV +0.0164），⑦ 甚至出现**整日零信号**（日注数 0~189）。⇒ **要垫就只垫 σ 腿，不要整窗砍。**

## 3. 为什么是 ⑤

### 3.1 七规则同台（14 天，2U/注，日级 bootstrap 2000 次 = 抽日期、保留抽中日内全部注）

| 规则 | n | 胜率 | 成交价 | EV/注 | P&L | P&L 95%CI | 单日最亏 | 日注数 | 落门 |
|---|---|---|---|---|---|---|---|---|---|
| ① 不过滤 | 3109 | 97.7% | 0.966 | +0.0232 | +72.1U | [+29.6,+116.3] | −1.8U | 190~251 | 0/13 |
| ② 纯美元 ≥63 美元 | 1458 | 99.6% | 0.985 | +0.0224 | +32.7U | [+22.4,+44.0] | +0.5U | 25~192 | 5/13 |
| ③ 纯 σ ≥1.0σ | 1469 | 99.5% | 0.987 | +0.0152 | +22.3U | [+11.1,+32.5] | −2.6U | 88~123 | 9/13 |
| ④ 联合 | 1747 | 99.4% | 0.984 | +0.0194 | +34.0U | [+21.1,+46.0] | −1.5U | 91~192 | 4/13 |
| **⑤ 定向 σ 腿 ≥40 美元** | 1536 | 99.6% | 0.985 | **+0.0240** | **+36.9U** | **[+25.7,+49.2]** | **+0.5U** | 27~192 | 3/13 |
| ⑥ 整窗 σ 下限 40 美元 | 1372 | 99.6% | 0.985 | +0.0247 | +33.9U | [+22.2,+46.0] | +0.1U | 8~192 | 4/13 |
| ⑦ 整窗 σ 下限 63 美元 | 963 | 99.6% | 0.984 | +0.0254 | +24.5U | [+15.4,+35.9] | +0.2U | 0~189 | 2/13 |

**读法**：⑤ 的 P&L 与 CI 下界在**"带过滤"的五格里都是最高**（② +32.7U/[+22.4]、
④ +34.0U/[+21.1]、⑥ +33.9U/[+22.2]、⑦ +24.5U/[+15.4]），单日最亏也是最好（+0.5U）；
**但不过滤的 ① 两项都更高**（+72.1U / CI 下界 +29.6U），代价是 3 个亏损日 + 76% 集中度
（跨族比较见 §3.2）。而 ⑤ ② ④ 三格的 CI **互相大幅重叠**（差 2.9U ≪ CI 宽 23.5U）
⇒ **按预设判据它们分不出来**：⑤ 的"最好"是点估计口径，不是显著性口径。

### 3.2 稳定性：⑤ 最好，但这与"总收益最高"是两件事

| 规则 | n | P&L | 亏损日 | 日 EV/注 范围 | 最好 4 天占 P&L | 最差日 | 日注数 | 前半/后半 |
|---|---|---|---|---|---|---|---|---|
| ① 不过滤 | 3109 | **+72.1U** | **3/14** | −0.0075~+0.0833 | **76%** | −1.8U | 68~251 | +8.2 / **+63.9** |
| ② 纯美元 | 1458 | +32.7U | 0/14 | +0.0040~+0.0317 | 52% | +0.5U | 25~192 | +22.2 / +10.5 |
| ④ 联合 | 1747 | +34.0U | 1/14 | −0.0119~+0.0327 | 54% | −1.5U | 28~192 | +20.5 / +13.4 |
| **⑤ 定向** | 1536 | +36.9U | **0/14** | **+0.0092**~+0.0327 | **50%** | **+0.5U** | 27~192 | +24.5 / +12.5 |

- ① 的**环境依赖是坐实的**：三个亏损日 = 08-19（−1.56U）/ 08-20（−0.71U）/ 08-24（−1.82U），
  日 EV 为负的也正是这三天；**最好的 4 天 = 08-25~28 连续四天（+55.1U，占总 76%）**。
- **但闸门没有提高每注期望**：① 的 EV/注 +0.0232 vs ⑤ +0.0240（差 0.0008），
  而 ① 的注数是 ⑤ 的两倍 ⇒ **闸门的实际作用是"把暴露减半"**：集中度 76%→50%、
  亏损日 3→0、日 EV 下界 −0.0075→+0.0092，代价是总收益近乎减半（+72.1→+36.9U）。
  ⇒ 与"过滤器唯一站得住的贡献是缩量降方差"这一判断**两次独立吻合**。

### 3.3 机制三条

1. **σ 腿会专门挑走贵的那批行**（所以给 σ 腿垫下限能提期望）。证据：全量热门侧按成交价分桶，
   **越便宜越赚**（0.80~0.90 → EV/注 **+0.0885**；0.99~1.01 → **+0.0111**），
   而便宜 ↔ 位移小（位移中位 20.7 美元 → 84.3 美元 与成交价同向）。
   在"位移 < 40 美元"那一群里：**过了 1.0σ 的 82 注成交价 0.9885（EV −0.0012）、
   没过 1.0σ 的 1009 注成交价 0.9370（EV +0.0284）**——σ 腿筛出来的恰恰是贵的那批。
   ⇒ **"美元值小 = 风险大"不成立**（"位移<40 美元"全体 1091 注 EV/注 **+0.0262**，
   比 ≥63 美元那批 +0.0224 还高，因为它们便宜）。**要动就动 σ 腿的门槛，不要按美元值排除行。**
2. **被 ⑤ 剔掉的那 211 注画像**：成交价 0.9816（联合格整体 0.9842）、该窗 1σ 中位 **25.8 美元**
   （整体 67.8）、位移中位 +44.7 美元（整体 +99.3）、胜率 97.6%（整体 99.4%）
   ⇒ 在**很静的窗**（σ 只有整体中位的 38%）里买**中等位移**的便宜热门侧，每注 EV **−0.0140**。
   这不是"小 σ 窗必然差"，只是这批行 net-flat。
3. **为什么只在 T=60 成立**：**高波动窗的折价在所有 T 都存在**，但"折价够不够付反转风险"
   随剩余时间变——T=150 上不足 σ 的位移是亏本买卖，T=60 上同一批净为正。
   故 σ 尺子在 T=150 赢、T=60 输；给 σ 腿垫下限在 T=60 是修正、在 T=150 是**砍主力**
   （见表 §4.4）。**⑤ 不是"更普适的规则"，只是 T=60 这一格内部的参数修正。**

## 4. 已知局限（写在这里，免得日后当新发现）

1. **样本里没有尾部事件**：本族本质是"在末分钟卖反转保险"——成交价 0.985 隐含 ~1.5% 失败率，
   而 14 天里 2002 注 ≥0.99 的样本只输 **8 注（0.4%）**。**事件级样本量是 14 天，不是 1536 笔**；
   跨月、跨波动率 regime 才是它的真实考验。**⑤ 的 0 亏损日不属于"抗环境"，只是这 14 天的产物。**
2. **多重比较**：⑤ 是从 T × 价格腿 × 位移腿 × σ 窗长 的网格里挑出来的（前身的候选格排名
   有 19 格以上，见 git `c5720af` §12.2）。样本内最好的一格天然带选择偏差；本项目反复出现的
   形态是"样本内最强的格子换成样本外后均值归零"（dog@0.2：样本内 EV +1.078 → 09-15 复验 +0.199）。
3. **⚠️ 40 美元这个取值不可辨识**（三条选择稳定性检验，13 个整日）：
   - **全期 argmax 是 35 美元不是 40**（+37.4U vs +36.2U），而两者之差 1.14U **全部来自
     1σ ∈ [35,40) 美元的那 37 注——37 注全赢、每注平均只赚 +0.031U**（成交价 0.97+）。
     ⇒ "最优落在 35 还是 40"由 37 注全赢决定 = 纯噪声。**30~50 美元是一整片平台**（+33.9~+37.4U）。
   - **13 个日期重采样 2000 次，argmax 落点**：35 → 45.0%、30 → 24.9%、
     **不设闸（=④）→ 21.4%**、25 → 8.8%、**40/45/50/55/63 → 0%（一次都没中）**。
   - **分半选择不稳定**：后半挑出 F=25 拿到前半用 → +20.1U，比固定 40 的 +24.5U **更差 4.4U**；
     **逐日前瞻**（只用历史挑、做下一天）三种种子下都**输给不加闸的 ④**（+19.4 vs +20.2U）。
   - **⑤ 相对 ④ 的全部增益（+2.95U / 13 天）来自 08-19 一天**（+5.15U，
     那天剔掉的 10 注里 3 注便宜热门侧（0.85~0.90）各亏满 2U）；**其余 12 天合计 −2.20U**。
   ⇒ **方向（给 σ 腿垫美元下限）站得住，取值不可辨识。不许调参**：调 35 = 过拟合 37 注全赢，
   去掉闸在 21% 的重采样里反而更优。只能当格登记，让纸面样本裁决。
4. **T 依赖：这条修正只在 T=60 成立**

   | 尾盘起点 | ② 纯美元 | ④ 联合 | ⑤ 定向 |
   |---|---|---|---|
   | T=150s | +13.3U | **+33.0U** | +16.0U（**反向**，砍掉 +17U） |
   | T=90s | +13.0U | −1.6U | −1.8U |
   | T=60s | +32.7U | +34.0U | **+36.9U** |

5. **频率不稳**：日注数 27~192（7.1×），**只有 3/13 天落在 90~120 注/日 的预设闸门内**
   （② 5/13、④ 4/13 同样不守门；只有 ③ 守门 9/13）。原因：主信号来自美元腿，而 63 美元是
   **固定美元阈值**——静窗里它等价于"要求很大的 σ"⇒ 信号枯竭，动窗里门槛相对变松 ⇒ 爆发

6. **纸面期（`data/v4`）无法事后复验本族**：纸面记录里只有"首次砸到 ≤0.20"的快照，

## 5. 纸面登记与预设判据

### 5.1 登记格

| | 规格 | 登记理由 | 样本内弱点 |
|---|---|---|---|
| **主推 = ⑤** | T=60 + `dev ≥ 63 美元` **或** `40 美元 ≤ sd ≤ dev` | EV/股、EV/注 双双为 ①~⑤ 五条最高（⑥⑦ 名义 EV/注 更高但总收益更低，见 §2）；0 亏损日、集中度最低、前后半最平 | 相对 ② 的增量只来自 78 注（B 格：+4.2U、日级 CI [+2.3,+6.5] 不含 0，但 **per-note Wilson 区间 [−0.0223,+0.0246] 含 0**）；门槛取值不可辨识（§4.3） |

**口径与回测 1:1**：照 §1.2。**同一批快照可离线算出全部五格**，纸面只记录、不下单。

### 5.2 预设判据与决策表（**先定后看，避免事后挑格**）

**结算时点**：UTC 日滚动满 **14 个完整日**，且该格注数 n ≥ **800** 时做第一次判决。

**主判据** = 日级 bootstrap（重采样日期 2000 次）P&L 的 95% 区间：

| P&L 95% 区间 | 判定 | 动作 |
|---|---|---|
| 下界 > 0 | **通过** | 进入下一阶段评估（半仓实盘 / 继续累积到 28 日） |
| 上界 < 0 | **判负** | 出局，不再投入 |
| 跨 0 | **不显著** | 延长到 **28 日**再判一次；28 日仍跨 0 ⇒ 判负 |

**辅助闸门**（任一不满足 ⇒ 只记录、不下结论，先查原因）：
1. **频率**：⑤ 应落在 **90~120 注/日**（本样本均值 110，但日间 27~192）。超出 ±30% 说明
   行情结构变了——dog@0.2 的 09-15 复验就是栽在频率闸门上（36.5/日 vs 计划 44±5）。
2. **结算核对**：随机抽 30 笔与 gamma 官方 outcome 逐笔核对（同 dog@0.2 的 30/30 抽样口径）。
3. **锚与 σ 就绪**：锚未到手（`anchor_exact=false`）或 `hist_bps=0` 的窗口**整窗不产出观测**
   （同引擎现行口径，决策 #13/#15），必须在 winstats 里可分辨。

**本段的纪律**：纸面结果若"看起来不错但不显著"，**不许**用"再等等看"或"换个阈值"把它救活
——上表就是裁判（§4.3 已经预告了 40 这个值会被重采样挑战）。

### 5.3 数据前提：引擎要落什么

⚠️ **这是纸面的前置条件**（§4.6）。引擎需新增一类记录（**只记录，不下单**）：

| 项 | 要求 |
|---|---|
| 采样 | **`rem ≤ 180` 起每秒一行**（约 181 行/窗 × 288 窗/日 ≈ 52k 行/日）——任意 T 都能离线算。嫌大则退为两帧（`rem≤150` 首帧 + `rem≤60` 首帧），代价是 T 不可再调 |
| 字段 | 四档报价 `yes_bid/yes_ask/no_bid/no_ask` + `binance spot` + `twap price` + `anchor` + `hist_bps` + `rem` + `book_latency_ms` + `spot_age_ms` |
| 文件 | **必须独立前缀**（如 `tail_*.jsonl`），**不得混进 `touches_*` / `windows_*` / `winstats_*`**——`windows_*` 是 σ 预热数据源，混入会以 Amp=0 污染其后 18 窗（CLAUDE.md 决策 #9 的教训） |
| 结算 | 复用 `ResolutionPoller`（gamma `umaResolutionStatus`），口径不变 |

## 附录 A：探索过程的结论清单（压缩，细节见 git `c5720af`）

1. **0.80 本身不是选择器**：T=60 时 86% 的窗快照价 ≥0.80、76% ≥0.90 ⇒ 价格腿只负责"便宜/贵"。
   **但这一刀切得有道理**：唯一系统性为负的价位带是 `[0.75,0.80)`（T=120 时 EV/股 −0.0531，
   0.75–0.77 细桶 −0.077）——**≥0.80 恰好切在负值区之后**。
2. **剩余时间决定"贵不贵"，也决定过滤器有没有用**：快照价中位从 T=240 的 0.670 升到 T=60 的 0.990；
   **T=120 上加任何过滤都救不回来**（剔除最好的 4 天后回到 0 附近或转负，−23.9U）；
   **T=60 上加过滤有用，但作用在方差上**：P&L +72.1U → +32.9U 减半，而剔最好 4 天后
   +17.0U → +16.7U **几乎不变**（降下去的正是那 4 天的超额），日正 11/14 → **14/14**、
   CI 收窄 3 倍。⇒ 这就是"半仓、天天正"的来源，也是 §3.2 结论的来源。
3. **"spot 与 TWAP 同向"（用户原题条件②）无增量**：ΔWR 仅约 +4pp、EV 差 ≈ +0.008 美元/股；
   门槛从 >0bps 扫到 >20bps，P&L **单调下降**。
4. **两个偏离量都能强预测方向，但都是已被定价的信息**：无条件口径下 `spot − twap_open`
   把 P(UP 赢) 从 14.0% 拉到 99.2%、`twap − twap_open` 从 20.2% 拉到 96.1%；
   可在"热门侧 ≥0.80"样本内，**胜率上升的同时成交价同步上升**，EV/股 在
   −0.007~+0.026 间抖动、**无单调性**；控价检验（同一价格带内比）显示 EV 不随偏离度上升、
   方向还随价格带翻转 ⇒ **过滤器在 T=120 没有独立 alpha**。**只有 T=150 的过滤器有独立信息**
   （价格 `[0.85,0.92)` 带内：全部 −0.0020 → spot≥1.0σ **+0.0497** → ≥1.6σ **+0.0954**）。
5. **T=60 的收益不是"价格顶到 0.99 天花板"造成的**：成交价 <0.99 的 **1107 注 EV/股 +0.0201
   （+49.8U）**，高于 ≥0.99 那 2002 注的 +0.0055 ⇒ **越便宜越赚**（§3.3 机制的来源）。
   但 +72.1U 里 **76% 来自 08-25~28 连续四天**，且同一机制在 T=120 上剔除最好 4 天后 −23.9U。
6. **σ 怎么估不是杠杆**：窗长 N=14 vs 现行 N=18 逐窗 **ρ=0.967**（逐窗比值 p10~p90 仅 0.84~1.14，
   几乎是同一个变量）；把 N 扫到 6~36、估计量从平均绝对变动换成均方根，**没有任何格位翻符号**。
   N 缩到 5（更局部：1σ 折美元 p90/p10 从 5.05× 升到 5.97×）反而把 ③ 拖差
   （T=60 spot≥1.0σ +22.3U → +18.1U，日级 bootstrap 下界 +10.9 → +0.4）。⇒ **不要在 σ 口径上调参**。
7. **T=150 上 σ 尺子是主力**（twap≥1.0σ +33.4U / spot≥1.0σ +37.5U），与 T=60 相反——机制见 §3.3。
8. **两把尺子是两个目标函数**：σ 尺子守频率（88~123 注/日、9/13 落门）、美元尺子守日 EV
   （全域为正、0 亏损日）——normalize 消除波动率就守住前者、钉死美元阈值才守住后者。
