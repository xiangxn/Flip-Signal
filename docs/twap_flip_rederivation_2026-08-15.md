## 背景与思路

Formula B（Binance 标定）在 TWAP 结算下被证伪（WR 17.2%/PF 0.87，见
`analyze_twap_calibration.py` 首轮结论）。本工作回到 2026-08-05 首次推导翻转策略的
路径，在 TWAP 结算口径下重做：

```
1. 事件级基率：全事件中有多少出现过一边 >0.7，其中多少最终翻转
2. 单特征筛选：分桶 + χ² + 95%CI + EV（对侧 ask 成交）
3. 理论检验：Binance 前置性 vs TWAP 特征
4. 组合探测：top 特征两两 2×2
5. Split 验证：按天交叉
```

**用户理论（假设 H3）**：Binance 数据 + Binance 结果成立（旧标定），
TWAP 数据 + TWAP 结果理论上也应成立，叠加 Binance 数据的前置性胜率最高。

前置性的精确含义：TWAP-60 是 60s 均线，结算 TWAP(T) = avg(spot[T-60,T])，
决策时刻已知其中 `max(0, 60-remaining)/60` 的样本；spot 与 twap 的缺口对剩余
TWAP 有机械拖拽。

## 铁律（无未来数据）

- 特征只用 ≤ 确认 tick（穿越 + confirm_delay_ticks=2，即 +10s）已知的信息
- 入场价 = 确认时刻对侧 ask = 1 - 触发侧 bid（实盘成交口径）
- 结算只用 `event.outcome`（TWAP 官方口径）
- `twap_close_price` / `close_price` 等窗口结束数据禁止进入特征
- 方向性特征统一"正 = 对翻转有利"

### 3. 特征筛选（χ² 显著者）

**关键教训（与 Formula B 死亡同源）**：高翻转率桶几乎都被确认期的成交价吃掉

**EV 来源反而是"低 fill"桶**：市场极度自信（触发侧 bid ≥0.80）或现货继续朝 PM
方向走时，fade 成本极低（fill 0.11-0.16），即便翻转率平庸也有正 EV。
新策略的优化目标应从"找高翻转率"转向"找翻转率 > fill 的组合"。

   （价差会吃掉一部分，但 +0.06~+0.20 的边际对 0.005-0.01 价差不敏感）
3. 每事件一注、仅首个穿越 —— 后穿越（反弹）无优势（77.2% 胜率 ≈ 均价 0.769 打平）

## 第三次迭代：独立 follow 回测（python/follow/backtest.py，2026-08-16）
