# 非对称 Spread 公式 & 双边策略

## 概述

本文档定义了一个统一的**非对称 Spread 分配公式**，适用于两类策略：

| 策略 | 方向 | 逻辑 |
|------|------|------|
| **买侧（Bid）** | 挂限价买单，低吸后 merge | 折扣买入，低价侧多折扣 |
| **卖侧（Ask）** | Split 后挂限价卖单 | 溢价卖出，低价侧多溢价（效果微弱） |

核心洞察：**无过滤时两种策略均亏损**。买侧单边成交遭遇逆向选择（买入的是市场正在抛弃的 token，胜率 0%），卖侧单边成交同样亏损（卖出的是市场追捧的 token，手中对家归零）。**仅有卖侧 + F8 过滤能产生正期望**——F8 通过筛选稳定性事件将单边率从 57% 压到 29%。

---

## 非对称 Spread 公式

### 定义

```
total_spread = S              # 总 spread 预算（买侧=bid_h+bid_l, 卖侧=sp_h+sp_l）
base = S / 2                  # 对称部分
imbalance = |yes_price - no_price|   # 价格偏离度 ∈ [0, 1]
tilt = min(k × imbalance, 0.95)     # 倾斜量，k 为倾斜系数

high_spread = base × (1 - tilt)     # 高价侧：少给
low_spread  = base × (1 + tilt)     # 低价侧：多给
```

### 直觉解释

- **价格平衡时（0.5, 0.5）**：imbalance=0, tilt=0 → 两侧对称
- **价格偏离时（0.7, 0.3）**：imbalance=0.4, tilt>0 → 低价侧多给
  - 高价 token 已接近上限 1.0，上涨空间小 → 少给 spread
  - 低价 token 离 0.0 远，上涨（卖侧）/ 下跌（买侧）空间大 → 多给 spread

### 参数选择

| 参数 | 买侧 | 卖侧 | 说明 |
|------|------|------|------|
| S（总 spread） | **0.18** | **0.26** | 总预算 |
| k（倾斜系数） | **1.8** | **0.1** | 买侧激进倾斜，卖侧接近对称 |

### 分配效果

|-----|-----|-----------|-----------|-----------|-----------|-----------|
| 0.50 | 0.50 | 0.00 | 0.090 | 0.090 | 0.130 | 0.130 |
| 0.52 | 0.48 | 0.04 | 0.084 | 0.096 | 0.129 | 0.131 |

**要点**：

## 策略一：买侧低吸策略（⚠️ 不推荐 — 实测亏损）

### 核心结论

**买侧策略实测亏损，不推荐上线。** 虽然 discount 买入 + merge 的双侧成交是盈利的（均 +$0.366/笔），但单侧成交遭遇严重的逆向选择——价格下跌触发买单意味着市场抛弃了该 token，成交方胜率趋近 0%。25% 的单侧率就足以吞噬全部利润。

| 变体 | 笔数 | 两侧% | 单侧% | 总 P&L | 结论 |
|------|------|-------|-------|--------|------|
| NoFilter + 公式 | 242 | 74.8% | 25.2% | **-$45.55** | ❌ 单侧逆向选择吞噬利润 |
| F8 避坑（避开 [0.88,0.95)） | 214 | 76.6% | 23.4% | **-$31.29** | ❌ 有所改善但仍亏损 |
| 固定参数 (0.03/0.15) | 242 | — | — | — | 与公式类似，同为负 |

> **为什么买侧在理论上有优势、实测却亏损？**
>
> 买侧的折扣买入确实降低了风险：即使 token 归零，亏损也只是折扣价而非全价。
> 但问题在于**逆向选择比折扣更大**——当 YES 价格跌到你的 bid 时（比如 0.70 → 0.62），
> 说明市场已经转向，YES 最终胜率趋近 0%。36 笔仅 YES 成交的交易中，YES 获胜 0 笔。
> 低价买入一个必输的 token，折扣再大也是亏。

### 参数

| 参数 | 值 |
|------|-----|
| 入场时间 | **220s**（开盘后 80s） |
| 热身期 | 60s |
| 每侧数量 | **5 share** |
| 公式 S | **0.18** |
| 公式 k | **1.8** |
| 过滤器 | 无（但不推荐此策略） |

### 回测详情（242 events, entry=220s）

| 指标 | 值 |
|------|-----|
| 总 Event | 242 |
| 两侧成交 | 181 (74.8%) | 均 P&L = **+$0.366** | 合计 = **+$66.33** |
| 单侧成交 | 61 (25.2%) | 均 P&L = **-$1.834** | 合计 = **-$111.87** |
| 仅 YES 成交 | 36 笔 | 均 -$2.005 |
| 仅 NO 成交 | 25 笔 | 均 -$1.587 |
| **总 P&L** | **-$45.55** |
| 笔均 P&L | -$0.188 |

### 逆向选择详解

买侧成交条件：`price ≤ bid = entry × (1 - spread)`，即价格**下跌**触发成交。

```
仅 YES 成交时发生了什么：
  1. YES 价格从 0.70 跌到 0.62 → 触发买单
  2. 市场正在抛弃 YES → 价格包含了信息
  3. 最终 YES 胜率 = 0% (36笔中0笔YES获胜)
  4. 以折扣价买入了一个必输 token → 净亏 $2.00/笔
```

## 策略二：卖侧 F8 策略

### 参数

| 参数 | 值 |
|------|-----|
| 入场时间 | **220s** |
| 热身期 | 60s |
| Split 金额 | 5 USDC → 5 UP + 5 DOWN |
| F8 阈值 | **> 0.95** |
| 公式 S | **0.26** |
| 公式 k | **0.1** |

### 执行流程

```
1. 距收盘 220s，计算 F8
2. 如果 F8 < 0.95 → 跳过
3. 计算 sp_h, sp_l = asym_formula(0.26, yes, no, 0.1)
4. Split 5 USDC → 5 UP + 5 DOWN
5. 挂限价卖单：
   - 如果 yes > no: yes挂 yes+sp_h, no挂 no+sp_l
   - 如果 no > yes: yes挂 yes+sp_l, no挂 no+sp_h
6. 未成交按结算价处理
```

### 回测结果（242 events, entry=220s）

| 变体 | 笔数 | 两侧% | 单侧% | 总 P&L | 结论 |
|------|------|-------|-------|--------|------|
| 无过滤 + 公式 (k=0.1) | 242 | 37.2% | 57.4% | **-$71.33** | ❌ 单侧率太高 |
| F8 > 0.95 + 公式 (k=0.1) | 24 | 70.8% | 29.2% | **+$9.07** | ✅ 唯一正期望策略 |
| F8 > 0.95 + 固定 (0.12/0.14) | 24 | 70.8% | 29.2% | **+$9.05** | 与公式几乎一致 |

卖侧的公式倾斜度极小（k=0.1），与固定参数效果几乎一致。F8 过滤是**必要条件**——不加过滤的 57% 单侧率是毁灭性的。

> **注意**：卖侧单边成交同样遭遇逆向选择。仅 YES 卖出时（价格上涨触发 ask），YES 本身胜率 100%，但我们已卖出 YES、手中持有 NO，而 NO 胜率 0%。每笔单侧成交均亏损 ~$1.73。F8 的价值在于将单侧率从 57% 降到 29%。

## 两种策略对比

| 维度 | 买侧低吸 | 卖侧 F8 |
|------|---------|---------|
| 过滤器 | 无（但实测亏损） | F8 > 0.95（**必须过滤**） |
| 入场时间 | 固定 220s | 固定 220s |
| 总 P&L (242ev) | **-$45.55** ❌ | **+$9.07** ✅ |
| 交易笔数 | 242 | 24 |
| 笔均 P&L | -$0.188 | +$0.378 |
| 两侧成交率 | 74.8% | 70.8% |
| 单侧率 | 25.2% | 29.2% |
| 资金占用/笔 | ~$4.61 | 5 USDC |
| 实盘复杂度 | 极低（挂两个买单） | 中（需要 split + 计算 F8） |
| 依赖特征 | 无（仅盘口价） | F8, 历史波动率 |

**结论：卖侧 + F8 > 0.95 是唯一正期望的策略。** 买侧虽然两侧成交率高、操作简单，但单侧逆向选择无法克服（成交即意味着该 token 大概率输）。卖侧必须配合 F8 过滤，将单侧率从 57% 压到 29% 才能盈利。交易频率低（10% 的 event 通过过滤）是卖侧的主要局限。

## F8 特征定义

```
F8 = 1.0 - min(|yes_end - yes_start| + |no_end - no_start|, 1.0)
```

- 计算窗口：[开盘, 入场时刻]
- F8 = 1.0：价格完全没动
- F8 ≥ 0.95：累计变动 < 0.05（几乎静止）
- **F8 ∈ [0.88, 0.95)：危险区间**，小幅波动但未形成趋势，容易只成交一侧
- F8 < 0.88：大幅波动，反而可以低吸（买侧）

## Python 实现

```python
def asym_formula(total_spread, yes_price, no_price, k):
    """非对称 spread 分配公式"""
    base = total_spread / 2
    imbalance = abs(yes_price - no_price)
    tilt = min(k * imbalance, 0.95)
    high_sp = max(base * (1 - tilt), 0.01)
    low_sp = min(base * (1 + tilt), total_spread - 0.01)
    return high_sp, low_sp

# 买侧
bid_h, bid_l = asym_formula(0.18, yes_price, no_price, 1.8)

# 卖侧
sp_h, sp_l = asym_formula(0.26, yes_price, no_price, 0.1)
```

## 风险提示

1. **逆向选择是核心风险**：无论买侧还是卖侧，单边成交都意味着市场已经选择了方向。买侧成交方胜率 0%（买入必输 token），卖侧成交方胜率 100%（已卖掉赢家，手中是输家）。这是策略最大的风险来源，不是折扣或溢价能弥补的。
2. **F8 过滤不能消除逆向选择**：F8 > 0.95 过滤后单侧率仍有 29%，只是把单侧量压到 both-fill 利润能覆盖的水平。
3. **样本量有限**：242 event，卖侧 F8 过滤后仅 24 笔交易，统计显著性不足。F8 的有效性可能在市场结构变化后衰减。
4. **链上成本**：未计入 gas 费。卖侧每笔 split + 2 笔卖单 ≈ 3 笔链上交易。
5. **做市商竞争**：如果其他做市商也挂低价买单/高价卖单，我们的单子可能排后面。
6. **极端行情**：BTC 单边暴涨暴跌时，F8 可能在入场后才被打破，导致意料外的单侧成交。
