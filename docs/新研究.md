# 任务：研究并实现 60s TWAP 未来 30 秒预测

## 一、背景

我们正在研究 Polymarket BTC 5m 市场。

该市场使用 BTC 的 60 秒 TWAP 作为最终结算相关价格机制的一部分。当前研究重点不是直接做交易策略，而是研究：

> 已知当前 BTC 实时价格，以及过去 59 秒的价格历史，能否实时预测未来约 20 秒的 60s TWAP 会如何变化？

我们希望先建立一个可靠的研究工具，并用历史数据验证预测误差，再决定是否将其用于浅洞策略。

---

# 二、核心数学定义

假设每秒有一个 BTC price：

```text
P[t-59], P[t-58], ..., P[t-1], P[t]
```

当前 60s TWAP：

```text
TWAP[t] = (P[t-59] + ... + P[t]) / 60
```

未来 k 秒的 TWAP：

```text
TWAP[t+k]
=
(
    P[t+k-59]
    + ...
    + P[t+k]
) / 60
```

在 t 时刻，我们不知道未来价格：

```text
P[t+1], ..., P[t+k]
```

因此需要构造：

```text
TWAP_pred[t+k]
```

---

# 三、首先实现最简单、最重要的 Baseline

不要一开始使用机器学习。

首先实现：

## Model A：Price Hold

假设未来价格保持当前价格：

```text
P_hat[t+j] = P[t]
```

那么：

```text
TWAP_pred[t+k]
=
(
    sum(P[t+k-59 : t])
    + k * P[t]
) / 60
```

注意窗口长度必须始终为 60 秒。

例如 k=20：

```text
TWAP_pred[t+20]
=
(
    P[t-39] + ... + P[t]
    + 20 * P[t]
) / 60
```

也可以使用等价的增量形式：

```text
TWAP_pred[t+k] =
TWAP[t]
+
(
    k * P[t]
    -
    sum(P[t-59 : t-60+k])
) / 60
```

请自行严格检查索引，避免 off-by-one。

# 四、实现第二个 Baseline

## Model B：Linear Extrapolation

估计当前 BTC 短期速度：

```text
v = (P[t] - P[t-5]) / 5
```

然后：

```text
P_hat[t+j] = P[t] + j * v
```

将预测价格代入未来 TWAP：

```text
TWAP_pred[t+k]
=
(
    sum(P_hat[t+1 : t+k])
    +
    sum(已知历史窗口中仍然存在的价格)
) / 60
```

其中 k=1...20。

短期速度窗口不要写死成最终方案。

请将：

```text
5s
10s
15s
20s
30s
```

设计成可测试参数。

# 五、实现第三个 Baseline

## Model C：Mean Reversion

假设实时价格相对于 TWAP 的偏离会逐渐衰减：

```text
P_hat[t+j]
=
TWAP[t]
+
(P[t] - TWAP[t]) * exp(-lambda * j)
```

lambda 作为参数进行实验。

测试不同的衰减速度。


如果未来价格保持当前价格：



# 十三、不要把“预测未来价格”和“预测 TWAP”混为一谈

研究重点是：

```text
Future TWAP prediction
```

而不是：

```text
BTC price prediction
```

Model A 的意义尤其重要：

即使完全不知道未来 BTC 会怎么走，只假设：

```text
未来价格 ≈ 当前价格
```

TWAP 本身由于窗口结构，仍然具有一定的可预测性。

我们要验证：

> TWAP 的“机械惯性”本身到底提供了多少可预测信息。

这是本研究最重要的问题之一。

# 十七、最终研究目标

最终希望得到一个实时函数：

```text
PredictTWAP(
    currentPrice,
    past59Seconds,
    horizon=20
)
```

输出：

```text
TWAP_pred_1s
TWAP_pred_2s
...
TWAP_pred_20s
```

以及：

```text
predicted Dist
=
TWAP_pred - TWAP_OPEN
```

但在进入交易策略之前，必须先用历史数据证明这个 projection 在真实 PM BTC 5m 数据上具有足够的稳定性和预测能力。

不是用 TWAP projection 单独定义浅洞。更准确地说：

用它来判断“当前这个浅洞会不会继续变深”，以及当前看到的 PM 极端价格是不是只是暂时的快慢价偏离。

我们之前的“浅洞”本质上是：

$$ Dist_t=TWAP_t-TWAP_{open} $$

比较接近 0，而 PM 某一边价格已经被打得很低。

现在加入未来 TWAP projection 后，就可以把判断从“静态浅洞”升级成“动态浅洞”。
