# Flip 策略胜率优化分析（2026-08-13）

> 数据集：`data_0/lab/`，2026-08-05 ~ 08-12，1719 个 5 分钟事件（完整日 6 天）。
> 分析脚本：`python/optimize_winrate.py`（baseline / features / search / validate / subtract 五段）。
> 结论落地：Formula B 精简公式，见 [flip_strategy_plan_2026-08-13.md](flip_strategy_plan_2026-08-13.md)。

## 1. 口径修正：yes/no_price 是 best bid，不是中间价

### 1.1 发现

`cmd/flip/main.go` 的 `bestBid()` 将订单簿**最优买价**写入 `yes_price/no_price`：

```go
collector.UpdatePolymarket(bestBid(yb), bestBid(nb), maxLatency(yb, nb))
```

双 token 互补市场（YES + NO = 1）下：

- 实盘 FAK **买入**对侧 token 成交在 **ask**：`对侧 ask = 1 - 触发侧 bid`
- 数据实测 spread（`1 - yes - no`）均值 **1.05 分**、中位数 1 分、p90 1 分
- 旧回测按「对侧 bid 成交」（`entry + other_delta`）**每笔系统性低估 ~1 分成本**

### 1.2 影响

| 口径 | n | WR | EV/笔 | P&L | PF |
|---|---|---|---|---|---|
| 旧口径（对侧 bid 成交 + bid gate）| 189 | 41.8% | +0.105 | +19.93 | 1.59 |
| **实盘口径（对侧 ask 成交 + ask gate）** | 188 | 41.5% | +0.094 | +17.70 | 1.51 |

实盘口径 = `fill = 1 - 触发侧bid[confirm]`，gate 同样按 ask 应用
（Trader 的 FAK 校验用最优卖价 vs max_price，`trader.go:249`）。

### 1.3 顺带发现的 Go 侧口径不一致

引擎 Price Gate（`engine.go:737`）用**对侧 bid** 判 gate，Trader 用**最优卖价（ask）**校验
——两处差一个 spread。引擎放行的信号可能被 Trader 拒绝，信号记录口径虚报。
方案文档中已列入修复清单。

## 3. 特征统计效力（train 集 3359 个候选，χ² 检验）

### 3.1 BTC 背离 = 最强特征（χ²=125.3）

方向校正后的背离度 `div = -btc_pos（YES侧触发）/ +btc_pos（NO侧触发）`，正 = BTC 与 PM 反向：

| 桶 | n | WR | EV/笔 |
|---|---|---|---|
| 背离强 (div > 0.3) | 111 | 55.0% | +0.291 |
| 背离中 (0.15~0.3) | 56 | 46.4% | +0.259 |
| 背离弱 (0.05~0.15) | 94 | **59.6%** | **+0.341** |
| 中性 (-0.05~0.05) | 533 | 31.1% | +0.065 |
| 同向弱 (-0.15~-0.05) | 203 | 27.1% | +0.033 |
| 同向强 (≤ -0.15) | 2362 | 23.3% | -0.002 |

- **76% 的候选是「同向穿越」**（BTC 与 PM 方向一致），EV≈0——纯噪声。
- 背离候选 EV +0.26~+0.34，是全体候选（~+0.03）的 ~10 倍。
- test 日（8/11-12）独立确认：背离 +0.173 vs 同向 +0.013，edge 持续。

### 3.2 成交价 fill 与胜率（χ²=118.4）

fill 越高胜率越高（确认越强），但 **fill ≥ 0.50 桶 WR 60.7%、EV 却转负 (-0.066)**——
纯追胜率会毁掉 EV。gate=0.45 是盈亏比的自然边界。

### 3.3 无效/反向特征

| 特征 | 结论 |
|---|---|
| F3 振荡（path_eff/noise/flips）| χ²=3.5, **p=0.32**——无统计效力 |
| F4/F5 低价入场 | 方向相反（越便宜 WR 越低），且用对侧 bid（不可成交价）判价 |
| path_eff < 0.4 否决 | 被否决的候选 EV +0.065 **好于**留下的平均（+0.03）——否决滤反了 |
| noise > 3 否决 | 该桶与整体无差异，纯减信号 |
| other_delta（确认回归）| 有效（χ²=65.7），但 od 越强 fill 越高，需 gate 兜底 |
| 触发侧 | 全候选层 YES 侧好于 NO 侧；**div 过滤后反转**（NO 侧 +0.342 vs YES 侧 +0.171）——div 池内两侧都做 |

## 4. 防过拟合框架

1. **完整日切分**：8/05 与 8/12 是半日数据，训练/测试只用完整日
   - Split A：train 08-06~08-10（5 日）→ test 08-11（1 日）
   - Split B：train 08-06~08-09（4 日）→ test 08-10~08-11（2 日）
2. **test 只展示不参与选择**，排序只看 train；train 信号数 < 20-25 的组合直接判无效
3. **单变量消融 + 圆整值网格**，拒绝精调阈值
4. **阈值平台检查**：参数在邻域内结果连续（非尖峰）才采信
5. **穿越语义双验证**：引擎的窗口边界伪穿越（价格全程 >0.7 时进入窗口的首个 snapshot 计为上升沿）与原始价格穿越语义分别回测，结果一致才采信
6. **逐日 bootstrap**：按日重采样给出逐日 EV 的 95% CI
7. **无未来数据核对**：背离度/振幅/od 全部在确认时刻已知；hist_avg_range 来自前 18 个已完成事件；outcome 仅用于结算

## 6. 减法路径：Formula B（最终采用）

### 6.1 拆除清单

| 拆掉的 | 依据 |
|---|---|
| F3 振荡 | §3.3 χ² 无效力 |
| F4/F5 低价入场 | §3.3 方向相反 + 用不可成交价 |
| F7 btc_extreme 加分 | 由 B1 背离硬过滤取代（加分 → 入场前提，更干净）|
| path_eff < 0.4 否决 | §3.3 否决滤反了 |
| noise > 3 否决 | §3.3 中性 |

保留三个信号条件（与策略哲学一一对应）：

```
B1 背离硬要求   div > 0.05       ← 「BTC 与 PM 反向」才有 flip edge（χ²=125）
B2 过度自信     range_exp < 0.5  ← 「BTC 没动但 PM 已 0.7+」（+2）
B3 确认回归     od 三档          ← 「确认期对侧回归」（+3/+2/+1）
score_entry = 2: 任一核心信号成立即触发（od>0.02 或 range<0.5）
```

### 6.2 结果（ask 口径，data_0 全量）

| | 当前参数 | 加法冠军A | **Formula B** |
|---|---|---|---|
| 信号数 / 8 天 | 188 | 28 | **126（~20/日）** |
| 胜率 (Wilson CI) | 41.5% (35-49) | 60.7% (42-76) | **46.0% (38-55)** |
| 单笔 EV | +0.094 | +0.293 | **+0.214** |
| 总 P&L | +17.70 | +8.21 | **+26.91** |
| 利润因子 | 1.51 | 3.37 | **2.60** |
| avg_fill | 0.321 | 0.314 | **0.247** |
| 负 EV 完整日 | 2/6 | 1/6 | **0/6** |
| Split A train/test | +0.111 / +0.015 | +0.260 / +0.383 | **+0.226 / +0.193** |
| Split B train/test | +0.109 / +0.068 | +0.244 / +0.450 | **+0.206 / +0.263** |

2 USDC stake 折算（股数 = 2/fill）：Formula B ≈ **+218 USDC / 8 天**（当前参数 ≈ +120）。

### 6.3 稳健性证据

- **双 Split 四象限全正**：+0.226 / +0.193 / +0.206 / +0.263
- **6 个完整日全部正 EV**（+0.16 ~ +0.35），唯一负日=半日 08-05（n=1）
- **原始穿越语义一致**：n=124，EV +0.221，P&L +27.36
- **od 阈值平台**：0.005 / 0.01 / 0.02 全在 EV +0.21 附近
- **min_div 阈值平台**：0.03 / 0.05 / 0.08 / 0.10 全在 +0.20~0.22
- **逐日 bootstrap**：均值 +0.148，95% CI 下界 -0.003（受半日 08-05 单笔拖累）
- **信号构成健康**：score=2 的 76 笔中 71 笔为纯 B2 信号（BTC 没动 + 背离），
  WR 46%、EV **+0.272**——「过度自信」才是核心，公式砍对了方向

### 6.4 可选激进变体（不推荐作默认）

min_div=0.0（只要 BTC 不与 PM 同向）+ sc>=2：n=303、EV +0.173、P&L +52.46，
但 WR 仅 41.9%，且 08-08 单日 129 笔（信号集中风险）。

---

## 7. 结论

1. **回测必须按 ask 口径成交**——旧口径每笔虚增 ~1 分，6 天累计高估 ~13% P&L。
2. **BTC 背离是最强且最稳定的特征**，应从「+1 加分」升级为「入场前提」。
3. **减法优于加法**：少特征 + 按新特征空间重标定门槛（score_entry=2），
   信号只减 33%，单笔 EV ×2.3，逐日全部为正。
4. 完整落地规格见 [flip_strategy_plan_2026-08-13.md](flip_strategy_plan_2026-08-13.md)。
