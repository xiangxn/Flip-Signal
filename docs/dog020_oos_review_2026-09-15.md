## 10. 附录：判据精算口径

- 单笔 P&L：赢 = 2/fill−2 ≈ +8.53U（fill 0.19 中位），输 = −2U；EV +0.633U；
  Var = 0.246·8.53² + 0.754·4 − 0.633² ≈ 20.5 → sd ≈ 4.5U/笔
- WR 的 sd（n=535）= √(0.246·0.754/535) ≈ **1.9pp**；n=400 时为 2.2pp
- 日 P&L sd ≈ 40.7U（14 天样本）→ 12 天总 P&L SE = 40.7·√12 ≈ **141U**
- 真值 = 回测（+339U）下：P(P&L ≤ −80U) = P(z ≤ −2.97) ≈ **0.15%**；
  P(P&L < +100U) ≈ 4.9%（→ §4 过线「站住」的假阴性率 ≈5%；真值=0 时误判「站住」率 ≈24%）
